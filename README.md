# Vector
Простая имплементация std::vector. Вместо итераторов использует указатели. 

Автоматически управляет памятью: выделение/освобождение через new[]/delete[], поддерживает правило 5 и индексацию

## Как тестировать?
В корне проекта:
```
mkdir build
cd build
cmake ..
make
```
А для запуска:
```
./vector_tests
```
