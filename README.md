# Vector
Простая имплементация std::vector. Вместо итераторов использует указатели. 

Управление памятью: автоматическое выделение/освобождение через new[]/delete[]

## Как тестировать?
В корне проекта:
```
mkdir build
cd build
cmake ..
make
```
А для запуска:
```
./vector_tests
```
